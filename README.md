# Slorg Studio

A small web app for customizing a Slorg mascot: mask a photo or flat color into its body
silhouette, toggle Mad Slorg Eyes, adjust the decorative spots, and export the result as a PNG or
SVG.

Live demo: https://rneopets.github.io/slorgstudio/

## Development

Requires [Bun](https://bun.sh).

```sh
bun install
bun dev
```

Build for production:

```sh
bun run build
```
